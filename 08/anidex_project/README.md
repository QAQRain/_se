# AniDex 動漫資料站

一個純前端的動漫資料網站，收錄 AniList 人氣前 500 名動畫。可以搜尋、依類型／年份／評分／狀態篩選，把喜歡的作品加入比較清單並排比較，所有篩選條件與比較清單都能用網址分享。

> **線上執行版**：<https://qaqrain.github.io/anidex/>

- 不需要資料庫、不需要後端、不需要安裝任何套件
- 不需要建置（no build），下載後直接開就能用

---

| 項目 | 需求 |

## 二、安裝方式

**不需要安裝。**

本專案是純靜態網頁，沒有任何安裝程式、沒有 `npm install`、沒有資料庫。把整個資料夾複製到任何位置即可使用。

---

## 三、開啟方式

有三種方式，任選一種：

### 方式 1：雙擊 `index.html`（最簡單）

在檔案總管中雙擊 `index.html`，網站會用預設瀏覽器開啟。

### 方式 2：雙擊 `start.bat`

雙擊 `start.bat`，會自動用預設瀏覽器開啟 `index.html`。

> 若 Windows 阻擋執行，對 `start.bat` 按右鍵 →「內容」→ 勾選「解除封鎖」即可。

### 方式 3：線上版

直接開啟 <https://qaqrain.github.io/anidex/>，功能與本機版完全相同。

---

## 四、關閉方式

**直接關閉瀏覽器分頁即可。**

本專案沒有背景程式、沒有常駐服務、沒有本機伺服器需要關閉，關掉分頁就完全結束。

## 五、功能說明

### 作品列表

- **關鍵字搜尋**：可用中文名、日文原名或英文名搜尋
- **類型篩選**：動作、冒險、喜劇、劇情、奇幻、懸疑、戀愛、科幻等
- **年份區間**：可設定起始與結束年份
- **最低評分**：6.0 分至 9.0 分
- **狀態篩選**：已完結、連載中、未播出、已取消、停播
- **排序**：人氣、評分、年份（新到舊／舊到新）、名稱

### 作品詳情

- 封面、評分、人氣、年份、形式、集數、單集長度、狀態、製作公司
- 類型標籤與作品簡介

### 比較功能

- 在卡片右上角按「＋」加入比較，最多 4 部
- 底部會出現比較列，顯示已選作品
- 比較頁以表格並排呈現，評分與人氣最高者以綠色標示

### 分享連結

- 所有篩選條件都會寫進網址，複製網址即可分享相同的篩選結果
- 每部作品都有獨立網址，例如 `index.html#/a/16498`

## 六、檔案結構

```
anidex/
├── index.html                 網站入口
├── styles.css                 樣式
├── app.js                     主程式（路由、篩選、比較）
├── start.bat                  Windows 開啟腳本
├── README.md                  本說明文件
└── data/
    ├── titles-zh.js           作品中文名對照表
    ├── anime-data-1.js        第 1～100 名
    ├── anime-data-2.js        第 101～200 名
    ├── anime-data-3.js        第 201～300 名
    ├── anime-data-4.js        第 301～400 名
    └── anime-data-5.js        第 401～500 名
```

資料檔是 JavaScript 檔（`window.ANIME_DATA = ...`），而不是 JSON，原因是直接用 `file://` 雙擊開啟時，瀏覽器基於安全性會阻擋 `fetch()` 讀取本機 JSON；改用 `<script>` 載入就能零設定執行。

---

## 七、更新資料（選用）

資料已經抓取完成並存放在 `data/` 內，**平常不需要更新**。若日後想重新抓取最新的人氣排行，需要 Node.js 18 以上，並自行執行 AniList GraphQL 查詢後覆蓋 `data/anime-data-*.js`。

查詢端點：`https://graphql.anilist.co`（POST）

## 八、資料來源與授權

- 資料來源：[AniList](https://anilist.co)（社群維護的動漫資料庫）
- 取得方式：AniList GraphQL API，依 `POPULARITY_DESC` 排序取前 500 名，已排除成人內容
- 封面圖片：由 AniList 的 CDN 直接載入
- 本專案僅供課程學習與展示使用，資料著作權屬於原權利人

## 九、已知限制

- 作品簡介為 AniList 提供的英文原文，介面其餘部分為繁體中文
- 中文名稱為人工整理的常見譯名，未收錄的作品會顯示日文原名
- 人氣排行會隨時間變動，本版資料為抓取當下的快照
- 比較清單儲存在瀏覽器的 `localStorage`，更換瀏覽器或清除網站資料後會消失
