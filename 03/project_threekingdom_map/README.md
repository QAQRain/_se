# 三國兵裝據點地圖

《戰意：三國》互動輔助地圖：把全地圖 63 個據點的兵裝製造情報、徵兵人口、兵團馬種、145 個資源點全部整理成一張可操作的互動地圖。點據點看兵裝與材料，點兵裝反查製造據點，資源需求即時計算，出門查資料不用再翻表比對。

## 功能一覽

- **63 個據點**：點擊任一據點，立刻顯示該處可製造的兵裝、所需材料與解鎖方式。
- **38 個兵裝／兵團**：點擊兵裝清單，地圖自動高亮所有能製造該兵裝的據點。
- **徵兵人口**：點擊人口（如鄉勇、河北壯士），高亮擁有該人口的據點；點兵裝只顯示其所需人口。
- **馬種取得**：良馬／軍馬顯示各騎兵兵團所需馬種，點擊馬可反查使用該馬的兵團。
- **資源需求計算**：切換「數量」欄位，合計所需材料自動乘以數量。
- **我的資源管理**：輸入手上庫存（皮／鐵／韌皮／精鐵），開啟「顯示不足警示」即標紅材料不足的部分。
- **資源點模式**：145 個資源點（含 Lv.1–4 等級），依類型與等級篩選顯示，可標記「已採過」。
- **雙模式切換**：「兵裝」與「資源點」一鍵切換，兩套介面完全獨立。
- **手機版**：介面自動改為直排，行動裝置也能用。

## 本機安裝與執行

網頁是純靜態檔案（無 build 步驟），跑任何靜態伺服器即可。因為資料用 `fetch` 載入，**直接用瀏覽器開 `index.html` 會無法運作**，必須透過 HTTP 伺服器開啟。

方法一（Python，免安裝套件，系統需有 python3）：

```sh
cd threekingdom_map
python3 -m http.server 8000
```

方法二（Node.js / npx）：

```sh
cd threekingdom_map
npx serve .
```

方法三（PHP）：

```sh
cd threekingdom_map
php -S localhost:8000
```

任一方式啟動後，瀏覽器開啟 <http://localhost:8000> 即可。

## 使用說明

### 模式切換

標題列的「兵裝｜資源點」按鈕切換兩種模式：

- **兵裝模式**：據點地圖＋兵裝／人口／馬側欄＋材料面板，不含資源點。
- **資源點模式**：整張地圖換成資源點地圖，顯示 145 個資源點，不含據點與側欄。

切換模式時自動清除所有選取與高亮。

### 兵裝模式

- **點擊據點** → 地圖左上方常駐面板顯示該據點可造的兵裝與材料，人口欄同步高亮所需人口。
- **點擊兵裝清單項目**（右側）→ 地圖高亮所有能製造該兵裝的據點（金色框），其餘據點變暗；再點一次取消。點兵裝時人口欄只剩該兵裝所需人口、馬欄只顯示所需馬種（不需馬的兵團顯示「此兵團不需馬」）。
- **點擊人口**（右側）→ 高亮擁有該人口的據點（藍色框）。同時啟動兵裝＋人口篩選時，只高亮同時符合的據點。
- **點擊馬**（右側）→ 高亮使用該馬種的兵團（紫色框），不改變據點高亮。
- **點擊兵團** → 面板下方顯示該兵團的「解鎖方式」（目前僅有解鎖條件，官方尚未提供完成條件）。
- **數量欄位**：調整數字，合計所需材料同步自動計算。
- **我的資源**：輸入皮／鐵／韌皮／精鐵庫存，勾選「顯示不足警示」後，不足的材料會標紅，方便備料。
- **重設按鈕**：清除目前的選取與高亮。

### 資源點模式

- **資源點**：皮／鐵／石／木／糧／馬以遊戲截圖顯示，驛站（白點）、關口（紅點）為原色點；外圈顏色＝等級（白 Lv.1／綠 Lv.2／藍 Lv.3／紫 Lv.4）。游標停留可看到「名稱・類型・Lv.x」。
- **已採過標記**：點擊資源點即標記「已採過」（打勾＋變灰，自動記憶在你的瀏覽器），再點一次取消。
- **類型切換**（右上角）：8 種資源類型按鈕，點擊開啟／關閉該類型的顯示。
- **等級篩選**（右上角）：「全部／Lv.1–Lv.4」多選開關；驛站與關口常駐顯示、不受等級影響。
- **重設按鈕**：清除選取、高亮，並一併清除全部的「已採過」標記。

### 縮放與移動

- 滑鼠滾輪（或觸控板兩指）放大縮小，以畫面中心為準。
- 右下角「＋／−／100%」按鈕可縮放或回到 100%。
- 按住地圖空白處拖曳可平移地圖。

### 手機版

- 介面自動改為直排：地圖 → 材料面板 → 兵裝／人口／馬清單。
- 縮放按鈕改在右上角，並針對觸控操作最佳化。

## 資料維護（給想自行更新資料的人）

所有資料都是 JSON，改資料不需動程式碼，位置如下：

- `data/markers.json`：63 個據點（座標為地圖百分比 0–100，左上角為 0,0）。
- `data/items.json`：38 個兵裝／兵團（材料、人口、馬種、星數、解鎖方式）。
- `data/populations.json`：7 種徵兵人口。
- `data/horses.json`：良馬／軍馬。
- `data/resources.json`：145 個資源點（類型、等級、座標）。

對應圖片放在 `assets/` 下（兵裝 `assets/soldier/`、人口 `assets/population/`、馬種與資源 `assets/resources/`、資源點截圖 `assets/res-points/`）。更換據點地圖背景時，需同步更新 `style.css` 內 `.map-wrap` 的 `aspect-ratio`（目前為 `1122 / 771`）。

## 部署到 GitHub Pages

1. 把整個資料夾推到 GitHub repo（`main` 分支）。
2. 本專案使用 GitHub Actions 自動部署（`.github/workflows/pages.yml`），push `main` 後約 10 分鐘完成。
3. 部署完成後網址為 `https://<帳號>.github.io/<repo名>/`。
4. **首次部署需在 repo 的 Settings → Pages 把 Source 設為「GitHub Actions」**（不是 `Deploy from a branch`），之後每次 push `main` 就會自動上線。
5. ⚠️ 若 push 被拒並顯示 repository rule violation，代表有本機素材被誤加進去（常見於 `git add -A`）。本 repo 的 `.gitignore` 已擋掉 `assets/map/` 原始截圖、`AGENTS.md` 與憑證檔，**請用 `git status` 確認後再 commit**。
