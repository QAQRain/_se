# 國立海嶼大學 校務行政系統（SAS_project）

以「大學方式」模擬的校務行政系統課程專題。Python Flask + SQLite 後端，
前端為單一深色 SPA（原生 JS + Chart.js），涵蓋教務、選課、學務、財務等完整模組。

## 功能模組

| 模組 | 說明 |
| --- | --- |
| 登入與權限 | 4 種角色：系統管理員 / 行政人員 / 教師 / 學生，每支 API 皆做角色驗證 |
| 儀表板 | 角色化統計：學生看 GPA/學分/課表/成績分布；職員看人數/開課/繳費率/缺曠餅圖 |
| 學生管理 | 系所＋年級＋關鍵字篩選、學生資料 CRUD、個人檢視（課表/成績單/獎懲/請假） |
| 教職員管理 | 教師職員 CRUD、兼任/專任、在職狀態 |
| 課程管理 | 開課 CRUD、修課名單（含加退選來源）、教師授課清單 |
| 課表查詢 | 依個人／系所年級查詢，週一~週日 × 節次網格渲染，辨識衝堂 |
| 點名 | 教師按日點名（出席/遲到/病假/…）、學生查自己的出缺勤、缺曠統計 |
| 成績 | 期中/期末輸入、自動算 GPA（4.3 制）、等第、分布圖、平均/最高/最低 |
| 選課 | 初選（≤4 志願＋學分上限 28）＝志願結算（依名額依序錄取）→ 加退選；熱門度排行 |
| 請假 | 學生申請（事/病/公假＋節次）、教師核准或駁回、依班級查詢 |
| 獎懲 | 記功嘉獎/申誡懲處登錄，學生可查個人紀錄 |
| 諮商輔導 | 學生發送求助自動派給系上輔導教師、約談紀錄登錄與查詢 |
| 學雜費 | 當期繳費單、線上繳費（ATM）、行政標記、繳費率 |
| 獎學金 | 書卷獎核定紀錄、學生個人獲獎查詢 |
| 公告 | 全校／系所公告發布與刪除 |
| 報表 | 學生名冊、課程清單、繳費清單、課程成績 CSV（UTF-8 中文檔名） |

## 安裝與啟動

Linux / macOS：

```bash
pip install flask
python app.py            # 首次啟動自動建庫並產生種子資料
# 開啟 http://localhost:5000
```

Windows：

```powershell
pip install flask
python app.py
```

產生乾淨種子資料（重建）：

```bash
python seed.py --force
```

## 資料規模（種子）

7 系 × 4 年級 ≈ 224 學生、57 教職員、183 門課（一般＋通識＋核心通識＋體育）＋2016 筆修課成績、點名、繳費單、獎助學金與公告，隨機擬真。

## 選課流程

0. 系統初始為 `closed`（已關閉）。
1. 「選課系統」管理員切到 `initial` → 學生登記 ≤4 志願（不可與已修課程衝堂）。
2. 管理員「執行結算」：依志願序＋課程名額錄取，超過上限（28 學分）者往後順延。
3. 切換到 `add_drop` → 學生可即時加退選（仍受名額與上限限制）。
4. 切回 `closed` 收尾。

## 編寫邏輯（系統架構）

```
SAS_project/
├── schema.sql          資料表定義（學院/系/課程/修課/選課/成績...）
├── db.py               SQLite 連線管理（WAL、thread-local、request 結束自動關閉）
├── seed.py             種子資料產生器（`--force` 重新產生）
├── app.py              Flask 後端：所有 REST API＋登入權限＋CSV 報表
├── templates/index.html  SPA 入口（深色主題殼，Tailwind/Chart.js 用 CDN）
└── static/
    ├── app.js          hash 路由＋各模組畫面
    └── style.css       深色主題樣式
```

### 後端
- 每次 request 由 `@app.teardown_request` 統一關閉連線，避免 SQLite 鎖庫。
- 登入用 `@login_required`＋`@roles_allowed("admin","clerk","teacher","student")` 做角色權限控管；權限不足一律回 `{"ok":false,"error":...}`。
- 回傳統一封裝：列表回 `data`、單一對象回頂層欄位（如 `/api/dashboard` 的 `base`）。
- 首次啟動（無資料庫）由 import 時的 `ensure_initialized()` 自動建庫＋種子。
- CSV 報表在「報表中心」下載，檔名含中文以 `filename*=UTF-8''` 編碼。

### 前端
- hash 路由：`#/students`、`#/courses/<id>`（修課名單）、`#/grades?c=<id>`（該課成績）；用 `menu()` 依角色過濾側欄。
- 依角色分支渲染（`if (me.role === "student") ...`），同一頁不同角色看到不同畫面。
- 圖表用 Chart.js：儀表板 bar/doughnut、成績分布 bar、選課熱門度 bar。
- 所有輸出經 `esc()` 跳脫，避免 XSS。

### 核心業務規則
- GPA 採台大 4.3 制；選課學分上限 28；初選志願上限 4。
- 選課三階段：`closed`（關閉）→ `initial`（初選志願）→ 結算 → `add_drop`（加退選），由管理員在「選課系統」切換並執行結算。
- 通識／體育／核心通識自動安排給各年級學生（同名課程只修一班）。
- 學生「諮商求助」會自動派給其系上的第一位在職輔導教師。
